Promotional vs Preventive: Indian alcohol, tobacco and pan masala ads

Research prototype · video-ad stance classifier · runs locally, nothing leaves this computer

1. How it works

Ad video
→
Speech transcript (Sarvam ASR)
+ on-screen text
→
TF-IDF (words 1-2, chars 2-5)
+ logistic regression
5 sampled frames
→
CLIP ViT-L/14 (frozen, pretrained)
mean-pooled → logistic regression
→
Average of the two probabilities
> 0.5 = promotional, else preventive

Only the small logistic-regression layers are trained (on 70-86 ads). CLIP is used as a fixed feature extractor. Either branch also works alone, which is what happens for a brand-new video with no transcript (image-only).

6. Limitations (read before quoting any number)

  • Labels: one human annotator plus an AI cross-check; there is no human-human agreement figure yet.
  • Circularity: labels were set largely from the same transcript and screen text the text model reads.
  • Style vs message: all preventive ads look like PSAs or films and all promotional ads like commercials, so the model may partly recognise style. It is weakest on preventive messages in film style.
  • Small data: 101 ads (70 train / 16 val / 15 test). The test set uses different campaigns and brands, but the same collection, era and sources; it does not test other countries or years.
  • Classes missing: no preventive pan-masala ads exist in the data; promotional tobacco has only 4.
  • Not a legal tool: "surrogate" advertising is treated here as a content-based research label, not a legal finding.
